# ELF test fixtures

These fixtures cover ELF layouts that are difficult to express with mocks.
They are test inputs, not release artifacts, and are excluded from the gem.

Third-party provenance and license information is recorded in
[`THIRD_PARTY_NOTICES.md`](../../THIRD_PARTY_NOTICES.md).

## Locally generated fixtures

`Makefile` builds most fixtures from `test.cpp` with a Linux C++ toolchain:

| Fixture | Purpose |
| --- | --- |
| `libtest.so` | Shared library with a SONAME |
| `static.elf` | Statically linked executable without a dynamic segment |
| `pie.elf` and `nopie.elf` | Position-independent and non-PIE executables |
| `rpath.elf` and `runpath.elf` | Existing `DT_RPATH` and `DT_RUNPATH` entries |
| `pie32.elf` | 32-bit x86 rewriting regression coverage |
| `nosection.elf` | ELF with section headers removed by `patch.rb` |
| `libbuildid.so` | Build-ID note relocation coverage |

Building `pie32.elf` requires a compiler with 32-bit multilib support. Building
`static.elf` requires the corresponding static C++ libraries.

`pef-compat.elf` is generated by `pef-compat-elf.rb`. It exercises interpreter
and RPATH/RUNPATH growth with the compatible saver. `empty-note` is a
hand-crafted compatibility fixture containing a non-empty `PT_NOTE` segment
without a section inside it; its original construction recipe is not present.

Committed ELF bytes can vary with compiler and linker versions. Regenerate them
only when a test requires it, review the binary metadata, and run the complete
Linux suite afterward.

## NixOS/patchelf-derived fixtures

`contiguous-note-sections.elf` is generated from
`contiguous-note-sections.s` and `contiguous-note-sections.ld`. It verifies that
back-to-back note sections with different alignments can be normalized without
being mistaken for a gap.

`libbig-dynstr.debug` contains debug data but no dynamic section. It verifies
that the compatible saver reports the absent dynamic table instead of raising an
unrelated Ruby exception.

See [`THIRD_PARTY_NOTICES.md`](../../THIRD_PARTY_NOTICES.md) for exact upstream
sources and terms.

## Syncthing regression fixture

`syncthing` is a 20 MB x86-64 executable from Syncthing 1.4.0. It captures a
historical layout where output from the default saver crashes, while output from
the compatible saver remains executable. The root-cause analysis is preserved in
[issue #15](https://github.com/Homebrew/patchelf.rb/issues/15), especially
[@david942j's explanation](https://github.com/Homebrew/patchelf.rb/issues/15#issuecomment-605767300).
The Linux-only specs exercise both paths without requiring the known defect to
remain.

This fixture should eventually be replaced by a small source-generated
reproducer. Its hashes, source release, and license are recorded in
[`THIRD_PARTY_NOTICES.md`](../../THIRD_PARTY_NOTICES.md).
